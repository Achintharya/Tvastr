# Owner download page (source only)

`/owner/download` is a top-level page in the regular website shell, separate from the customer portal and `/owner/approve`. It does not add a public navigation/download card, expose customer business data or replace the old public ZIP/link. Fresh website password and verified TOTP use a per-mount memory-only Supabase client with persistence/refresh/URL token capture off. The shared client factory preserves the existing approval page's separate storage key and behavior. Portal auth is never reused or signed out.

The page submits only `release_id:current` and `platform:win32-x64` to the fixed HTTPS owner service's `/api/owner/download`, using the same public Vite Supabase variables and `VITE_OWNER_SERVICE_URL` as approval. Password goes only to Supabase, bearer only to fixed owner service, credentials omitted and no-store. Owner identity is enforced server-side; hidden links, email/isAdmin hints or frontend checks are not security. Service errors show no internal storage detail. No release gives an unavailable message, not a fake artifact.

On success, display authenticated version/platform/size/final ZIP SHA256 and a link lasting at most 60 seconds. Save buttons provide exact signed manifest bytes, detached signature and public publisher certificate for the separately trusted panel verification runbook. A certificate delivered with an archive cannot authenticate its own fingerprint. Verify the FULL ZIP signature/hash before extracting, with an independently verified publisher certificate pin and a separately trusted verifier. EXE Authenticode alone does not cover bundled trust/sidecars. Self-signed certs do not become publicly trusted by this page.

The dedicated identity session ends after each attempt or unmount. Link and metadata stay only in component memory and clear at expiry/clear/unmount. S3 link holders can reuse/forward it while live; completed downloads can be copied and an in-progress transfer may continue beyond link expiry. Policy revocation prevents new links, not immediate invalidation of an issued one. This tradeoff was explicitly selected for v1.

No real artifact, account/MFA change, hosting secret, private bucket, certificate operation or live activation is part of this source PR. Host CSP/HTTPS/redaction/exact service origin and vendor release/policy/storage checks precede separately approved activation. No customer portal/session or commercial download-route migration.
